# 100-hour learning track

| Stage | Hours | Proof |
|---|---:|---|
| Requirements, C4, ADR | 8 | Reviewed architecture |
| ACID and R2DBC | 12 | Concurrency and rollback tests |
| Reactor and API | 10 | Backpressure/error handling tests |
| Saga and compensation | 14 | Failure history and reconciliation |
| Terraform, networking, EKS | 18 | Reproducible deployment |
| GitLab CI/CD and Helm | 12 | Verified release and rollback |
| DevSecOps | 10 | Security reports and blocked release |
| Observability and DR | 10 | Runbook execution evidence |
| Final design defense | 6 | ADR trade-off interview |

For each topic: What, Why, How, Failure, Verification, Trade-off. Do not claim mastery until you can
reproduce results, explain alternatives, and diagnose a deliberate failure without guidance.
